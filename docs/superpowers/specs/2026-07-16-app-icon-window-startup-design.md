# 应用图标配色与启动窗口稳定设计

## 目标

1. 保留 Easy Agent Pilot 当前图标的品牌造型，仅将高饱和蓝色体系替换为与应用主题一致的浅色中性体系。
2. 消除主窗口启动时先显示较小尺寸、随后突然变大的视觉跳变。

## 图标设计

- 保留现有导航箭头、星标、圆环、光效、圆角轮廓、元素位置和比例，不重新设计图形。
- 主背景使用暖白到浅暖灰的柔和渐变，对应现有工作台的 `#fbfbfa`、`#f4f4f2` 与 `#e9e9e5` 色域。
- 原白色导航箭头和浅色圆环改为炭黑及中性深灰，以确保浅色背景上的可读性。
- 黄色星标作为唯一高饱和强调色保留。
- 原蓝色背景光晕与蓝色装饰点改为中性灰或低饱和暖灰；不得引入新的蓝色背景。
- 以 1024×1024 主源生成 Tauri 所需的 PNG、ICNS、ICO、Windows Store 与 iOS 图标资源，确保各平台资源一致。

## 窗口行为

- 将 `tauri.conf.json` 中主窗口初始尺寸从 800×600 调整为 1200×900，与 `windowState` 当前默认尺寸一致。
- 保持主窗口启动时隐藏，窗口状态初始化完成后再显示。
- 已保存且合法的用户窗口尺寸和最大化状态仍优先恢复，不清除用户偏好。
- 不修改最小尺寸、可缩放、最大化、居中和窗口状态持久化行为。

## 验证

- 检查所有生成图标的尺寸、Alpha 通道与格式，抽查 32px、128px、512px 视觉清晰度。
- 验证首次启动采用 1200×900，已有合法状态时直接恢复保存尺寸，显示前不出现 800×600 中间态。
- 运行项目要求的类型检查、Lint、前端测试、Rust Clippy 与构建门禁。

## 非目标

- 不重绘或更换品牌符号。
- 不调整应用内部主题色变量。
- 不改变窗口状态数据库结构或 Dock 展开时的窗口加宽行为。
